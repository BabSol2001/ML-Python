# 🛠️ Industrial Predictive Maintenance Engine (GraphRAG + DGL GNN + Kubernetes)

سرویس هوشمند هیبرید برای پایش سلامت تجهیزات صنعتی و پیش‌بینی ریسک خرابی قطعات با تلفیق گراف دانش متنی (**GraphRAG**)، گراف محاسباتی شبکه‌های عصبی (**DGL GNN**) و حافظه پویا.

---

## 🏗️ معماری سیستم

این سیستم از ۴ لایه اصلی تشکیل شده است:

1. **GraphRAG DB (`prdctv_mtn_grp_rag.py`):** پایگاه دانش متنی جهت استخراج اطلاعات کاتالوگ، تجهیزات کاندید و دستورالعمل‌های نگهداری.
2. **DGL GNN Engine (`prdctv_mtn_grp_gnn.py`):** مدل گراف عصبی بر پایه PyTorch و DGL جهت محاسبه عددی و تفکیک‌شده درصد ریسک خرابی (`Failure Risk %`).
3. **FastAPI Main Service (`prdctv_mtn_grp_app.py`):** سرویس مرکزی ارائه REST API و مدیریت یکپارچه درخواست‌ها روی پورت `8007`.
4. **Container & K8s Orchestration:** مدیریت کانتینرسازی با Docker Compose و دپلویمنت ایزوله در Kubernetes.
